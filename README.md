# 📝 Professional To-Do App

A modern and responsive To-Do App built using HTML, CSS, and JavaScript.

## 🚀 Features

- Add Tasks
- Delete Tasks
- Mark Tasks as Completed
- Search Tasks
- Dark Mode Toggle
- Progress Bar
- Task Counter
- Local Storage Support
- Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 Project Preview

This To-Do App helps users manage daily tasks efficiently with a clean and modern user interface.
